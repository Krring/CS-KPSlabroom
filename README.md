# เว็บไซต์ห้องปฏิบัติการชีวนิเวศของแบคทีเรียและการควบคุมเชื้อสาเหตุโรคพืชโดยชีววิธี

เว็บแบบ static สำหรับ GitHub Pages ไม่ต้อง build ไม่ต้องติดตั้งอะไร

## โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ (ปกติไม่ต้องแก้)
assets/style.css      สีและรูปแบบตัวอักษร
assets/app.js         ตัวแสดงผลและข้อความเมนูสองภาษา
data/site.json        ชื่อแล็บ ที่อยู่ อีเมล ลิงก์จองนัด ลิงก์คลังความรู้
data/research.json    หัวข้องานวิจัย
data/members.json     สมาชิก
data/publications.json ผลงานตีพิมพ์
data/services.json    บริการตรวจวิเคราะห์
data/news.json        ข่าวและกิจกรรม
img/                  รูปสมาชิกและรูปกิจกรรม
```

## แก้เนื้อหาบน GitHub (ไม่ต้องใช้โปรแกรมอื่น)

1. เปิดไฟล์ใน `data/` บนหน้า GitHub แล้วกดรูปดินสอ (Edit this file)
2. แก้ข้อความในเครื่องหมาย `" "` ระวังอย่าลบเครื่องหมาย `,` `{ }` `[ ]`
3. กด **Commit changes** เว็บจะอัปเดตภายในประมาณหนึ่งถึงสองนาที

ทุกข้อความมีสองภาษา `"th"` และ `"en"` รายการที่มี `"example": true` จะแสดงป้าย "ตัวอย่าง" เมื่อใส่ข้อมูลจริงแล้วให้ลบบรรทัดนี้ออก (และลบ `,` ที่บรรทัดก่อนหน้า)

### เพิ่มสมาชิก
คัดลอกบล็อก `{ ... }` หนึ่งคนใน `data/members.json` แล้ววางต่อท้าย (คั่นด้วย `,`) ช่อง `group` ใช้ค่าใดค่าหนึ่ง:
`pi` `postdoc` `phd` `ms` `ug` `staff` `alumni`
นิสิตปัจจุบันทุกระดับจะเรียงต่อกันเป็นแถวเดียว เว็บใส่ป้ายระดับ (ป.เอก ป.โท ป.ตรี) ให้เองจากช่อง `group` ส่วนช่อง `note` คือหัวข้อวิจัยสั้น ๆ สำหรับศิษย์เก่า ใช้ `role` เป็นวุฒิและปีที่จบ และ `note` เป็นที่ทำงานปัจจุบัน
รูปควรครอปเป็นสี่เหลี่ยมจัตุรัส ประมาณ 600×600 พิกเซล พื้นหลังเรียบใกล้เคียงกันทั้งแล็บ
ใส่รูปโดยอัปโหลดไฟล์เข้าโฟลเดอร์ `img/` แล้วใส่ `"photo": "img/ชื่อไฟล์.jpg"`

### หน้าผลงานตีพิมพ์
หน้าแรกแสดง 10 เรื่องล่าสุด แล้วมีปุ่มไปหน้า `publications.html` ซึ่งแสดงทั้งหมดแยกตามปี และกรองช่วงปีได้ ทั้งสองหน้าอ่านจาก `data/publications.json` ไฟล์เดียวกัน ชื่ออาจารย์ (Sakdapetsiri C / Chirapanda C) จะเป็นตัวหนาอัตโนมัติ

### ตัวเอียงสำหรับชื่อวิทยาศาสตร์
ครอบชื่อด้วยดอกจัน เช่น `*Phytophthora* spp.` หรือ `*Bacillus subtilis*` เว็บจะแสดงเป็นตัวเอียง ใช้ได้ในหัวข้อวิจัยของสมาชิก หัวข้องานวิจัย และชื่อผลงานตีพิมพ์
ผลงานใหม่ที่ระบบดึงจาก ORCID จะยังไม่เป็นตัวเอียง ให้เติมดอกจันเองในไฟล์ `data/publications.json` (ระบบจะไม่เขียนทับ)

### เพิ่มผลงานตีพิมพ์
ใส่ `doi` แบบไม่ต้องมี https เช่น `"doi": "10.1099/ijsem.0.001234"` เว็บเรียงตามปีให้เอง

### ตรวจไฟล์ก่อน commit
ถ้าไม่แน่ใจว่ารูปแบบถูกไหม วางเนื้อหาไฟล์ที่ https://jsonlint.com เพื่อตรวจ ถ้าไฟล์ผิดรูปแบบ หน้าเว็บจะแสดงข้อความว่าโหลดข้อมูลไม่สำเร็จ

### คลังความรู้สำหรับสมาชิกแล็บ (หน้า lab-members.html)
ปุ่ม "สำหรับสมาชิกแล็บ" มุมบนขวาเปิดหน้านี้ รายการทั้งหมดอยู่ใน `data/kb.json` แยกเป็นหมวด (`categories`) แต่ละเรื่องมี
- `title` ชื่อเรื่องสองภาษา
- `url` ลิงก์ Google Docs ถ้ายังไม่มีเอกสาร ใส่ `""` เว็บจะแสดงป้าย "กำลังจัดทำ"
- `desc` คำอธิบายสั้นใต้ชื่อเรื่อง (ไม่ใส่ก็ได้)
- `keywords` คำค้นเพิ่มเติม ไม่แสดงบนหน้าเว็บ ใช้กับช่องค้นหา ใส่ทั้งคำไทยและอังกฤษคั่นด้วยเว้นวรรค

ช่องค้นหาค้นจากชื่อเรื่อง คำอธิบาย และ keywords ส่งลิงก์ผลค้นหาได้ เช่น `lab-members.html?q=autoclave`
สิทธิ์เปิดเอกสารกำหนดที่โฟลเดอร์ใน Google Drive ไม่ใช่ที่หน้าเว็บ

## เปิดใช้ GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้ว Save
3. รอสักครู่ จะได้ที่อยู่เว็บ `https://<username>.github.io/<ชื่อ repository>/`
   (ถ้าตั้งชื่อ repository เป็น `<username>.github.io` ที่อยู่จะเป็น `https://<username>.github.io/`)

## ผลงานตีพิมพ์อัปเดตอัตโนมัติจาก ORCID

ไฟล์ `.github/workflows/update-publications.yml` จะรันทุกวันจันทร์ 08:17 น. ดึงรายการจาก ORCID แล้วเติมชื่อผู้แต่ง เล่ม และหน้าจาก Crossref ลงใน `data/publications.json`

- รายการที่เพิ่มเองในไฟล์ (ไม่อยู่ใน ORCID) จะไม่ถูกลบ
- ช่องที่แก้เองแล้วจะไม่ถูกเขียนทับ ระบบเติมเฉพาะช่องที่ว่าง
- สั่งรันทันทีได้ที่แท็บ **Actions** → Update publications from ORCID → **Run workflow**
- ครั้งแรกให้ไปที่ Settings → Actions → General → Workflow permissions เลือก **Read and write permissions** เพื่อให้ระบบบันทึกไฟล์ได้
- แก้อีเมลติดต่อในตัวแปร `MAILTO` ใน `scripts/update_publications.py` เป็นอีเมลแล็บ (Crossref ขอให้ระบุ)

## ลิงก์ที่ต้องใส่ใน data/site.json

### ตารางนัดพบอาจารย์ (หน้า contact.html)
1. เปิด Google Calendar บนคอมพิวเตอร์ → Create → **Appointment schedule** ตั้งช่วงเวลาว่าง ระยะเวลานัด สถานที่ (พบที่แล็บ หรือ Google Meet) และเพิ่มคำถามในฟอร์มจอง เช่น "เรื่องที่ต้องการคุย"
2. เปิดตารางนัดนั้น → **Share** → **Website embed** → **Inline booking page** คัดลอกโค้ด แล้วนำเฉพาะลิงก์ในเครื่องหมาย `src="..."` มาใส่ที่ `bookingEmbedUrl`
3. ลิงก์หน้าจองแบบปกติ (Copy link) ใส่ที่ `bookingUrl` ใช้กับปุ่ม "เปิดในหน้าต่างใหม่"
ถ้ายังไม่ใส่ลิงก์ หน้าติดต่อจะแสดงข้อความให้ส่งอีเมลแทน

### แบบฟอร์มส่งข้อความ (หน้า contact.html)
ส่งข้อความเข้าอีเมลอาจารย์ผ่าน Google Apps Script และเก็บสำเนาไว้ใน Google Sheet
1. เปิด https://script.google.com สร้างโปรเจกต์ใหม่ วางโค้ดจาก `scripts/contact-form.gs`
2. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone** แล้วอนุญาตสิทธิ์
3. คัดลอก Web app URL (ลงท้าย `/exec`) ใส่ที่ `contactFormEndpoint` ใน `data/site.json`
ถ้ายังไม่ใส่ URL ปุ่มส่งจะเปิดแอปอีเมลของผู้ส่งพร้อมข้อความที่กรอกไว้แทน

- `bookingUrl` ลิงก์หน้าจองนัดจาก Google Calendar (Appointment schedule)
- `membersPortalUrl` ลิงก์ Google Sites คลังความรู้สำหรับสมาชิกแล็บ (ตั้งสิทธิ์ให้เฉพาะบัญชีที่อนุญาต)

ระหว่างที่ยังไม่ใส่ลิงก์ ปุ่มจะพาไปที่ส่วนติดต่อแทน
